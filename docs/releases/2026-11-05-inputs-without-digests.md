# Подготовка измерений без собственных digest

Из обычного `summary` и диагностических вариантов удалены собственные SHA runtime, исходников,
подготовленных скриптов и пакетов. Производители, форматы данных, читатели, вспомогательные команды
и действительные тесты изменены вместе. Архивные отчёты и прежние выпуски не переписываются.

`src/sources/files.ts` содержит только функциональный выбор и копирование файлов и защиту путей.
`SourceSelection` сохраняет штатный Git SHA выбранного источника; `InstalledPackage` перечисляет
явно выбранные пути установки без `packageHash`. Вход runtime содержит `path` и `version`.
Live-входы с удалёнными digest-полями отклоняются; совместимый старый договор не предоставляется.

`RunRecord.preparedScripts` содержит `PreparedScript`: `kind`, `path` и при необходимости
`sourceMapPath`. Старые `PreparationReceipt`, `sourceHash`, `preparedHash` и поле `preparation`
больше не используются текущими запусками. Исторический импорт переносит реальные результаты,
статусы и наблюдения; старое доказательство подготовки не становится новым наблюдением.

Доказательство инструментирования по обходу и SHA всех файлов расширений удалено. `packageCoverage`
хранит явный список запрошенных расширений и наблюдения действительных событий; по ним не
устанавливается наличие физической копии пакета или полнота инструментирования. Статусы неполноты,
отдельные часы, процессные записи и реальные фазы измерений сохранены.

Нативные Git, npm lock и контрольные суммы штатного Arch-пакета сохранены. Копирование выбранных
исходников в рабочий вариант остаётся функциональной подготовкой. Сохранение времени файлов для
нативного `sitemap lastmod` не используется как проверка свежести. Сравнение результатов читает
фактические bytes двух выбранных файлов, без digest и сохранённого графа доказательств.

До изменения обычный `summary` вызывал `probeQuarto` с полным чтением 4–5 runtime-файлов для SHA и
`preparePandocData` с digest исходного и подготовленного init. Experiment дополнительно повторял
runtime-проверки для вариантов, считал treeHash выбранных пакетов и обходил исходники расширений для
package coverage. В новой цепочке эти вычисления отсутствуют; нужные чтения для запуска, копирования
и преобразования сохранены. Ускорение полного курса не измерялось и не заявляется.

Адресные проверки запрещают `crypto.subtle.digest` во время реальной подготовки `summary`, установки
выбранных файлов, подготовки init и сравнения результата. Отдельные отрицательные случаи проверяют
удалённые live-поля и package rows, а также чтение исторического v2 без изменения архива. Типизация
выполняется для настоящих исходников, команд и тестов с действительными зависимостями. Полные
рендеры курса, старые матрицы и архивный TERM-пакет не входят в эту проверку.
