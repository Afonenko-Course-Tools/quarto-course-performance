## Запись после каждого принятого этапа

Добавлять краткую запись: task ID; worker/reviewer IDs; BASE..HEAD всех
затронутых репозиториев; фактические проверки и пути к результатам; два verdict
review; fix round/open findings; принятые решения; следующий конкретный шаг.
Не отмечать задачу выполненной до проверки фактов. После compaction сверять
этот журнал с active ledger, Git и рабочими деревьями, не перезапускать готовые задачи.

Для незавершённого этапа сохранять branch/worktree, dirty/untracked данные,
точный текущий шаг, следующую команду, состояние подагентов и ожидаемые ответы.
Не сохранять токены или другие секреты.
