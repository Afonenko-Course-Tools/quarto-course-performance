# Performance: требования и план реализации

Дата подготовки: 12 октября 2026 года. Пакет предназначен для последующей реализации Codex. Сейчас подготовлены документы; программный проект, изменения расширений и PR ещё не созданы.

## Последние указания пользователя

1. При **старте реализации** получить актуальные исходники Java и подключённых расширений из GitHub. Ни локальные каталоги, ни ревизии, обнаруженные при подготовке документов, не являются источником пилота.
2. Спроектировать чистую архитектуру производительности. Прежние внутренние механизмы можно заменить; разрешены существенные изменения внутренних API.
3. Использовать гибрид: небольшая библиотека и постоянная разметка значимых операций, внешние benchmark, выборочные CPU-профили и автоматическая подробная трассировка для углублённого анализа.
4. В обычной сборке курса сбор метрик должен быть выключен и не оказывать ощутимого влияния на производительность.
5. Совместно разработать отдельный проект профилирования и PR к соответствующим расширениям; обкатать и проверить систему на Java.
6. До реализации собрать требования и план, провести рецензию согласованности. Содержательные противоречия обсуждать с пользователем.

Эти указания заменяют прежние предложения о пилоте на текущих локальных репозиториях и обязательном сохранении старой телеметрии.
